# Naked Skin

Сайт бренда кожаных обложек для блокнотов ручной работы: лендинг, конструктор обложки и список кадров для будущей съёмки. Next.js 15, TypeScript, Tailwind, шесть языков, без бэкенда и фотографий — весь визуал на SVG-чертежах.

```bash
npm install
npm run dev        # http://localhost:3000
npm run lint       # ESLint + проверка переводов
npm run build
```

Документация — [docs/](docs/README.md): продукт, архитектура, конструктор, языки, эксплуатация и журнал решений.
