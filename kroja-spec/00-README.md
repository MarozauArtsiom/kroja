## Для кого текущий MVP

**Для мастера, который будет делать изделия и снимать их.** Не для пользователей, не для рынка.

Две задачи, обе главные:
1. **Мотивировать** — сайт должен выглядеть как бренд, который уже существует и продаёт, чтобы мастер захотел присоединиться
2. **Объяснить съёмку** — какие кадры, ракурсы, комбинации, требования

Отсюда два уровня качества внутри одного MVP:

| | Лендинг | Конструктор и `/shotlist` |
|---|---|---|
| Стандарт | **Production-ready** | Прототип-спецификация |
| Изображения | SVG-иллюстрации в эстетике бренда | Схематические чертежи |
| Копирайт | Финальный | Черновой |
| Ощущение | «Это уже работает» | «Вот что нужно от тебя» |

**Блокеров нет.** Фотографий в проекте не будет вообще — весь визуал построен на 6 готовых SVG и типографике. Цена временно единая: 300 zł за любой размер.

## MVP в одном абзаце

Три страницы: **лендинг**, **конструктор**, **список кадров**. Лендинг доведён до production-ready — настоящие фото, цены, финальный текст, Lighthouse ≥ 95: он должен читаться как действующий магазин. Конструктор показывает схематические чертежи обложки с выносками — что в кадре, чего быть не должно, каким именем ляжет файл. `/shotlist` собирает матрицу кадров и печатается на A4. Корзина завершается резервом конфигурации, а не тупиком. Стек — чистый Next.js без бэкенда и платформы. Срок — 11–14 рабочих дней.

**Критериев успеха два:** мастер захотел участвовать — и не задал ни одного вопроса о съёмке.
