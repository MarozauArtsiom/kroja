# 07 — User Journey Map и флоу

⚠️ **Контекст v0.4.** Этот файл описывает **целевое состояние продукта**, а не задачу текущего MVP. MVP адресован мастеру и служит объяснением состава съёмки (`01-mvp-scope.md`).

Карта нужна, чтобы решения конструктора принимались с оглядкой на конечного пользователя, а не переделывались потом. Этапы 6–9 и метрики воронки актуальны только после запуска для пользователей.

### Путь единственного зрителя MVP

| Шаг | Что делает мастер | Что должен вынести |
|---|---|---|
| 1 | Открывает лендинг | Какие сюжетные кадры нужны и в каком контексте они стоят |
| 2 | Идёт в конструктор | Что варьируется; почему кадров 36, а не 188; что размер снимать не надо |
| 3 | Переключает ракурсы | Чем отличаются `front` / `open` / `detail`, что должно быть в фокусе |
| 4 | Читает плашку «NOT IN FRAME» | Снимать без шнура и без гравировки |
| 5 | Открывает `/shotlist` | Полный список с именами файлов, печатает |
| 6 | Задаёт вопросы | Если вопросы о съёмке остались — MVP не сработал |

## 1. Journey Map: полный путь (включая то, что за пределами MVP)

Этапы 1–5 покрыты MVP. Этапы 6–9 показаны, чтобы понимать, куда всё ведёт, но в разработку сейчас не входят.

|---|---|---|---|---|---|---|---|:---:|

| 4 | **Конфигурация** ⭐ | Собрать «свой» предмет | `/configurator` | Превью, свотчи, цена, срок | Перебирает комбинации | Перегруз опциями, паралич выбора, нет отклика превью | Прогрессивное раскрытие, мгновенное превью, живая цена в sticky-панели | ✅ |
| 5 | **Намерение** | Убедиться, что не ошибся | Корзина | Полная конфигурация текстом, цена, срок | Кладёт в корзину, шлёт ссылку близким | Срок 14 дней пугает; передумал у последнего шага | Срок показан в конструкторе, а не в конце; shareable URL для «покажу жене» | ✅ |

## 4. Три сценария, которые надо пройти вручную перед релизом

**Сценарий A — «Себе, на десктопе».**
Пришёл из Instagram → пролистал лендинг до кожи → выбрал Crazy Horse → в конструкторе перебрал 5 цветов → добавил гравировку с именем → положил в корзину.
*Проверяем:* мгновенность превью, читаемость цены, понятность гравировки.

**Сценарий B — «В подарок, с телефона, в транспорте».**
Пришёл по ссылке → сразу нажал `Build yours` → выбрал размер по схеме габаритов → выбрал цвет → **скопировал ссылку и отправил в мессенджер** → вернулся через час с другого устройства по этой ссылке.
*Проверяем:* восстановление конфигурации из URL, работу на 360 px, sticky-панель поверх мобильной клавиатуры.

**Сценарий C — «Ломающий».**
Открыл `/configurator?size=xl&leather=pull-up&color=olive&engraving=🔥🔥🔥` → быстро перещёлкал десяток свотчей → нажал «назад» → добавил ту же конфигурацию дважды → перезагрузил страницу.
*Проверяем:* устойчивость парсера, отсутствие гонок загрузки изображений, поведение history, дедупликацию в корзине, персистентность.
