# 04 — Конструктор ⭐

Ядро продукта. На него уходит примерно половина всего времени разработки MVP.

---

## 1. Принципы

**Превью — схематический SVG-чертёж, а не фото, не рендер и не 3D.** MVP адресован мастеру и объясняет ему состав съёмки (см. `12-schematic-assets.md`). Схема покрывает 100% комбинаций и подписывает имя будущего файла.

**Ни одного спиннера.** Переключение любой опции даёт мгновенный отклик. Со схемами это бесплатно — сетевых запросов нет вообще.

**Ничего не скрывается.** Недоступная опция показывается затемнённой с причиной, а не исчезает. Исчезающие опции ломают ментальную модель — человек не понимает, что произошло.

**Цена и срок всегда на экране.** Sticky-панель, видна на любом скролле, на любом разрешении.

- Превью сверху, фиксированная высота 42vh, `aspect-ratio` задан заранее (нулевой CLS)
- Миниатюры ракурсов — горизонтальный скролл под превью

- Sticky-панель снизу, высота 72 px, с `env(safe-area-inset-bottom)`
- При открытии клавиатуры (ввод гравировки) превью схлопывается до 20vh, чтобы поле было видно

## 4. Матрица совместимости

Не каждый цвет существует в каждой коже. Правила — данными, не в коде:

```ts
// content/availability.ts
export const leatherRules = {
  'veg-tan':     { colors: ['natural','cognac','chestnut','black'],        sizes: ['a6','b6','standard','a5'] },
  'crazy-horse': { colors: ['cognac','chestnut','olive','black','navy'],   sizes: ['a6','b6','standard','a5'] },
  'pull-up':     { colors: ['cognac','black','burgundy'],                  sizes: ['b6','standard','a5'] },
} as const;

// Наличие конкретной комбинации — правится вручную
export const stock: Record<string, 'in_stock' | 'made_to_order' | 'unavailable'> = {
  'veg-tan_natural':     'in_stock',
  'veg-tan_cognac':      'in_stock',
  'crazy-horse_navy':    'made_to_order',
  'pull-up_burgundy':    'unavailable',
  // …
};
```

### Три статуса и их отображение

| Статус | Вид свотча | Подпись | Срок |
|---|---|---|---|
| `in_stock` | обычный | — | 5 рабочих дней |
| `made_to_order` | обычный + точка-индикатор | «Made to order» | 10–14 рабочих дней |
| `unavailable` | 40% opacity + диагональная штриховка | «Currently unavailable» | — |
| не существует в этой коже | 25% opacity | «Not available in {leather}» | — |

### Разрешение конфликтов

**Пользователь меняет кожу, текущий цвет в ней не существует:**
1. Цвет автоматически меняется на ближайший доступный (порядок приоритета задан списком в контенте)
2. Показывается неблокирующий тост на 4 с: `Color changed to Cognac — Burgundy isn't available in Crazy Horse`
3. Событие `config_conflict_resolved` в аналитику

**Пользователь меняет кожу, текущий размер в ней недоступен:** та же логика, приоритет — сохранить размер, а не кожу (размер выбирается осознаннее). То есть если выбран `a6` и пользователь жмёт `pull-up`, где A6 нет — карточка `pull-up` заранее показана недоступной с подписью `Not available in A6`, клик по ней не проходит.

**Клик по `unavailable`:** не меняет конфигурацию, открывает мини-форму «Notify me when available» (email + текущая комбинация).

## 5. Ценообразование

```ts
// lib/pricing.ts — все суммы в грошах
total = basePrice[size]
      + leatherDelta[leather]
      + (engraving.text.trim() ? ENGRAVING_PRICE : 0)
      + inserts.reduce((s, i) => s + insertPrice[i.type] * i.qty, 0)
      + (giftBox ? GIFT_BOX_PRICE : 0)
```

**Плейсхолдеры для MVP** (финальные — после расчёта юнит-экономики, см. `11-legal-and-open-questions.md`):

| Позиция | PLN (гроши) | Отображение |
|---|---|---|
| Любой размер | 30000 | 300 zł |
| + Crazy Horse | 3000 | +30 zł |
| + Pull-up | 5000 | +50 zł |
| + Гравировка | 4000 | +40 zł |
| + Вкладыш | 2500 | +25 zł |
| + Коробка | 3500 | +35 zł |

**Отображение изменения:** при росте или падении цены число в sticky-панели анимируется коротким счётчиком (200 мс) и на 600 мс подсвечивается. Связь «действие → цена» должна быть визуально очевидной, иначе пользователь не понимает, за что платит.

**Рядом с ценой каждой платной опции** — явная дельта: `Crazy Horse +30 zł`. Никаких сюрпризов в итоге.

## 6. Превью: схематические чертежи

⚠️ **Изменение v0.4.** Фотографий нет, съёмка вынесена за пределы MVP, а сам MVP адресован мастеру — чтобы он понял, что снимать. Поэтому превью — **схематический SVG-чертёж**, а не имитация фотографии.

Полная спецификация визуального языка, ракурсов и страницы списка кадров — в `12-schematic-assets.md`. Здесь только поведение внутри конструктора.

### Почему чертёж, а не правдоподобный рендер

Правдоподобный рендер создаёт две проблемы ровно для той аудитории, ради которой делается MVP:
1. Мастер может решить, что фотографии уже есть
2. Мастер может начать копировать освещение и постановку с рендера, а рендер их не задаёт

Чертёж читается однозначно — как техническое задание. Плюс он дешевле в реализации, чем текстурные фильтры.

### Что показывает схема

```
слой 4: имя файла              — моно, под схемой: crazy-horse_cognac_front.webp
слой 3: плашка «NOT IN FRAME»  — красным: cord, engraving, props
слой 2: выноски                — что должно быть в фокусе
слой 1: рамка кадра            — пропорция кропа
слой 0: контур обложки         — пропорции из coverMm выбранного размера,
                                 штриховка по типу кожи,
                                 пунктир шва по периметру,
                                 линии-страницы по числу вкладышей (ракурс open)
        чип цвета в углу       — квадрат hex + название текстом
```

Цвет **не заливается** внутрь контура: чертёж не изображает цвет кожи, он его называет. Смена цвета меняет чип и подпись.

### Три ракурса

`front` (4:5), `open` (4:3), `detail` (1:1). Переключаются миниатюрами под превью. Каждый показывает свою геометрию кадра и свой набор выносок — это и есть объяснение мастеру, чем ракурсы отличаются.

### Как показывается размер

**SVG-схемой** под превью: контур формата в реальных пропорциях, габариты в мм, полупрозрачный силуэт телефона (150×70 мм) для масштаба. Решение не зависит от наличия фото и остаётся неизменным навсегда.

Отдельно важно для мастера: подпись `Size is shown by this diagram, not by photography — one shot per leather × colour covers all sizes`. Это объясняет, почему кадров 36, а не 144.

### Что на что реагирует

| Смена оси | Что меняется в схеме |
|---|---|
| Размер | Пропорции контура, схема габаритов. **Имя файла не меняется** — размер не входит в ключ |
| Кожа | Штриховка, подпись, имя файла |
| Цвет | Чип и подпись, имя файла |
| Нить | Цвет пунктира шва |
| Шнур | Ничего — плашка «keep out of frame» напоминает почему |
| Гравировка | Ничего в кадре; подсвечивается пунктирная зона гравировки |
| Вкладыши | Число линий-страниц в ракурсе `open` |

Строки «имя файла не меняется» и «шнур не рисуется» — не мелочь оформления, а главное сообщение MVP.

### Переключение

Перерисовка мгновенная, сетевых запросов нет. Переход анимируется CSS-transition 150 мс. `aspect-ratio` контейнера фиксирован — CLS = 0. Prefetch и fallback в MVP не нужны: схема покрывает 100% комбинаций.

## 7. Гравировка

| Параметр | Значение |
|---|---|
| Максимум символов | 20 |
| Разрешённые символы | латиница, польские диакритики, кириллица, цифры, пробел, точка, дефис, амперсанд |
| Запрещённые | эмодзи, спецсимволы, переводы строки — блокируются на вводе с подсказкой |
| Шрифты | 2 варианта: serif, sans |
| Позиции | нижний правый угол обложки, корешок |
| Живое превью | да, с задержкой 120 мс после ввода |
| Счётчик | `12 / 20`, краснеет на 18+ |

**Только пробелы = пусто.** Доплата не начисляется, слой не рендерится.

**Модалка подтверждения перед добавлением в корзину:** если гравировка заполнена, при клике «Add to cart» показывается диалог с крупным рендером текста:

> **Check your engraving**
> `ARTSIOM`
> Engraving is permanent and cannot be changed after the order is placed.
> `[Edit]` `[Confirm and add]`

Это единственное место в MVP, где мы намеренно ставим препятствие — цена ошибки здесь максимальная.

## 8. Состояние в URL

```
/configurator?size=a5&leather=crazy-horse&color=cognac&thread=natural
              &cord=black&engraving=ARTSIOM&font=serif&pos=bottom-right
              &inserts=2:dot&box=0
```

URL — **единственный источник истины** для конфигурации. Компоненты читают из `useSearchParams`, пишут через `router.replace` (без записи в историю на каждый клик — иначе кнопка «назад» превратится в отмотку каждого свотча; в историю пишем только смену размера и кожи).

### Зачем обязательно

- Шаринг конфигурации — ключевой сценарий для подарочной покупки («покажу жене, что беру»)
- Восстановление при возврате из корзины
- Пресеты с лендинга: `?size=a6` из карточки размера
- Пошаговая воронка в аналитике без отдельного трекинга состояния

### Валидация входа

```ts
// lib/config-url.ts
parseConfigFromUrl(params) → { config, warnings[] }
```

| Ситуация | Поведение |
|---|---|
| Параметр отсутствует | Подставить дефолт |
| Неизвестное значение (`color=turquoise`) | Дефолт + warning |
| Неизвестный параметр (`utm_source`) | Игнорировать молча |
| Валидные по отдельности, но несовместимые (`pull-up` + `olive`) | Ближайшее доступное + баннер `This combination isn't available — we've selected the closest match` |
| Гравировка с недопустимыми символами | Очистить недопустимые, оставить остальное |
| Гравировка длиннее 20 | Обрезать |

Парсер **никогда не бросает исключение** и никогда не оставляет пользователя на пустом экране.

### localStorage

Последняя конфигурация сохраняется. При заходе на `/configurator` без параметров и при наличии сохранённой — баннер вверху опций:

> `Continue where you left off?` `[Restore]` `[Start fresh]`

Автоматически не восстанавливаем: пользователь мог прийти за другим.

## 9. Корзина (P2 — см. `01-mvp-scope.md`)

Клик «Add to cart» → открывается drawer справа (на мобайле — снизу, полноэкранный).

**Содержимое позиции:**
- Миниатюра превью (front)
- Название: `KROJA A5 · Crazy Horse · Cognac`
- Полная конфигурация списком: нить, шнур, гравировка (курсивом, как введена), вкладыши, коробка
- Срок изготовления
- Цена
- `Edit` → возврат в конструктор с восстановленной конфигурацией из URL
- `Remove`

**Внизу drawer:**
- Итог
- Блок-заглушка вместо чекаута (см. `01-mvp-scope.md`):

> **We're not selling yet.**
> Leave your email and we'll notify you first when pre-orders open — with 15% off your first order.
> `[email]` `[Notify me]`

Отправка → `POST /api/notify` с email + всеми конфигурациями из корзины. Ответ — подтверждение прямо в drawer, без редиректа.

Корзина живёт в `localStorage`, переживает перезагрузку, счётчик в шапке.

## 10. Доступность (WCAG 2.1 AA)

- Каждая группа свотчей — `role="radiogroup"` с `aria-label`, навигация стрелками, `roving tabindex`
- **Цвет никогда не единственный признак:** у свотча всегда есть текстовое название рядом или в tooltip, доступном с клавиатуры
- Недоступные опции: `aria-disabled="true"` + `aria-describedby` с причиной, они остаются в табуляции (чтобы скринридер сообщил, почему нельзя)
- `alt` превью обновляется при смене конфигурации: `KROJA A5 notebook cover, Crazy Horse leather, cognac colour, front view`
- Изменение цены анонсируется через `aria-live="polite"`
- Тосты конфликтов — `role="status"`
- Видимый focus ring минимум 2 px, контраст ≥ 3:1
- Интерактивные зоны ≥ 44×44 px
- Модалка гравировки: фокус-трап, `Esc` закрывает, фокус возвращается на кнопку

## 11. Граничные случаи — чеклист для тестирования

- [ ] Прямой заход на `/configurator` без параметров → дефолтная валидная конфигурация
- [ ] Заход с полностью битым URL → не падает, показывает дефолт
- [ ] Заход с несовместимой комбинацией → подмена + баннер
- [ ] Смена кожи, при которой недоступен текущий цвет → подмена + тост
- [ ] Смена кожи, при которой недоступен текущий размер → карточка кожи была недоступна, клик не проходит
- [ ] Гравировка из одних пробелов → доплата не начисляется
- [ ] Гравировка из эмодзи → символы не вводятся
- [ ] Вставка длинного текста в поле гравировки → обрезается до 20
- [ ] Быстрое переключение цветов подряд → нет мерцания
- [ ] Любая валидная комбинация даёт корректную схему (дыр быть не может по определению)
- [ ] Имя файла под схемой соответствует ключу `{leather}_{color}_{angle}`
- [ ] Смена размера НЕ меняет имя файла
- [ ] Плашка «NOT IN FRAME» присутствует на всех трёх ракурсах
- [ ] Кнопка «назад» после 10 переключений свотчей → возврат на лендинг, а не отмотка свотчей
- [ ] Добавление двух разных конфигураций → две отдельные позиции в корзине
- [ ] Добавление одинаковой конфигурации дважды → увеличение количества, не дубль
- [ ] Перезагрузка страницы с товаром в корзине → корзина сохранена
- [ ] Работа на 360 px без горизонтального скролла
- [ ] Открытие клавиатуры на мобайле при вводе гравировки → поле видно
