# 14 — Что нужно от мастера

Список всего, что мастер должен предоставить проекту. Разбит на три пакета по срочности: без первого не согласуется спецификация, без второго не запускается сайт с фото, третий делает контент глубже.

Этот файл — основа разговора при показе мока.

**Порядок на встрече:** сначала сайт — лендинг, конструктор, как меняются схемы при выборе цвета и кожи; затем `/shotlist`; затем пакеты 1 и 2. Ничего запрашивать заранее не нужно.

---

## Пакет 0 — отменён

Пилотная фотосъёмка убрана из плана: фотографий не будет ни сейчас, ни к показу мока. Лендинг и конструктор построены на схематической графике и типографике.

Съёмка полной матрицы остаётся в планах на будущее — список кадров генерируется страницей `/shotlist` и обсуждается с мастером на встрече как задача следующего этапа, а не как условие показа.

---

## Пакет 1 — Во время показа мока: данные для согласования

Это ответы, без которых матрица кадров не фиксируется. Всё — устно или списком в мессенджере, никаких документов.

### 1.1 Ассортимент реально доступного

| Вопрос | Зачем |
|---|---|
| Какие **типы кожи** есть в работе прямо сейчас? (в споке заложены veg-tan, crazy horse, pull-up — это гипотеза) | Оси конструктора и штриховки схем |
| Какие **цвета** физически есть в каждой коже? | Матрица `availability.ts` → число кадров |
| Какие комбинации он **может, но не держит** (под заказ)? | Статус `made_to_order` в конструкторе |
| Какие **размеры** реально кроятся? (заложены A6/B6/Standard/A5) | Ось размеров |
| Ограничения совместимости: есть ли кожа, из которой нельзя сделать какой-то размер? | Правила конфликтов |

### 1.2 Параметры для контента конструктора

| Вопрос | Зачем |
|---|---|
| Толщина кожи по типам (мм) | Спецификация в конструкторе |
| Вес готового изделия по размерам (г) | Карточки размеров |
| Реальное время изготовления одного изделия | Поле «Ready in N days» |
| **Сколько обложек реально делаешь за месяц** — устойчиво, месяц за месяцем, а не в теории | Расчёт очереди производства. **Самый важный вопрос встречи:** это, а не запас кожи, определяет, сколько заказов сайт может принять (`16-capacity-and-platform-plan.md`) |
| **Сколько кожи уходит на обложку каждого размера** (дм², с запасом на раскрой) | Модель остатка кожи |
| Что делать, если заказов придёт больше, чем ты успеваешь | Определяет, останавливать приём или растягивать срок |
| Цвета нитей, которые он использует | Ось нити |
| Варианты шнура/резинки | Ось шнура |
| Гравировка/тиснение: может ли, каким способом, какие ограничения по длине и символам | Ось гравировки — сейчас заложено ≤20 символов, 2 шрифта, 2 позиции. Проверить, что это реализуемо |
| Сколько вкладышей вмещает каждый размер | Ось вкладышей |

### 1.3 Данные о происхождении кожи

| Вопрос | Зачем |
|---|---|
| Откуда кожа: страна, дубильня (если известна) | Секция S4 лендинга — происхождение продаёт |
| Тип дубления по каждому типу | Тексты о материалах |
| Как каждая кожа ведёт себя со временем: царапины, патина, растяжение | Тексты «через 6/12/36 месяцев» и таблица сравнения |
| Что считается нормой, а что браком: складки, следы насекомых, разнотон | Блок «This is not a defect» — критичный для снижения возвратов |
| Правила ухода: чем обрабатывать, чем нельзя | Аккордеон Care |

Формат ответов свободный — голосовое сообщение подходит. Переработка в тексты — наша сторона.

## Пакет 2 — Для съёмки: изделия и кадры

Передаётся после согласования матрицы. Основной документ — распечатанный `/shotlist`, этот раздел его дополняет.

### 2.1 Физические изделия

| Что | Сколько | Требования |
|---|---|---|
| Обложка каждой комбинации кожа×цвет из финальной матрицы | по 1 шт | **Без шнура, без гравировки** — оба накладываются на сайте программно |
| Один размер на всю матрицу | — | Размер в кадре неотличим; масштаб на сайте показывает схема. Рекомендуемый — B6 или Standard: средние пропорции |
| Вкладыши для ракурса `open` | 2–3 шт | Чистые, без записей |
| Одно изделие «с историей» | 1 шт | Любой его личный ношеный кожаный предмет — для будущего кадра патины (не блокирует запуск) |

### 2.2 Сами кадры

Полный список с именами файлов — в `shotlist.md`. Сводка требований:

| Требование | Значение |
|---|---|
| Продуктовая матрица | ~36 кадров: каждая комбинация в 3 ракурсах (front 4:5, open 4:3, detail 1:1) |
| Постоянство | Внутри одного ракурса: одинаковый угол, свет, расстояние, фон для всех комбинаций |
| Фон | Единый нейтральный на всю матрицу |
| Разрешение | ≥ 2400 px по длинной стороне, без сжатия мессенджерами — передавать файлами, не фото в чат |
| Обработка | Без ретуши текстуры кожи; цветокоррекция — наша сторона |
| Сюжетные кадры | ~11: hero, макро шва (боковой свет, 4–5 стежков в кадре), макро фактур каждой кожи (≥2000 px), «не дефект» (складки и отметины крупно), комплект-раскладка |
| Кадры процесса | 5–6: раскрой → торцевание → разметка → седельный шов → обработка кромки → финиш. **Снимаются во время реальной работы** — единственная группа, которую нельзя доснять постановочно. Плюс 1 портрет за работой, лицо видно |

### 2.3 Как передавать

Google Drive / WeTransfer, оригиналы без сжатия. Имена продуктовых файлов — по `shotlist.md` (`crazy-horse_cognac_front.jpg`); если переименовывать неудобно — сгруппировать по папкам `{кожа}/{цвет}/`, переименуем сами.

## Пакет 3 — Углубление контента (не блокирует ничего)

- 2–3 истории из практики: необычный заказ, сложный ремонт, реакция клиента — для секции Craft и будущего блога
- Фото мастерской и инструмента
- Его собственный ответ на вопрос «почему седельный шов, а не машинный» — своими словами, из этого получится самый честный текст на сайте
- Первые настоящие отзывы, когда появятся покупатели. **Выдуманных не бывает** — до этого секция отзывов скрыта

---

## Чего от мастера НЕ нужно

Чтобы не пугать объёмом:

- Никаких текстов — только устные ответы, переработка наша
- Никакого профессионального фотооборудования — современный телефон при дневном свете покрывает требования, важнее постоянство ракурса и фона
- Никаких новых изделий для пакета 0 — снимается то, что уже сделано, любое
- Никаких изделий со шнуром и гравировкой — наоборот, они испортят кадры
- Не все размеры — один на всю матрицу
- Не всё сразу — пакет 1 это разговор на час, пакет 2 согласовывается по объёму (можно начать с 2 кож или без ракурса `detail` — варианты в `12-schematic-assets.md`, раздел 9)
