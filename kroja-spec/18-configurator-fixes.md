# 18 — Правки конструктора: начинка обложки, две резинки

**Версия:** 1.0 (из черновика v0.3) · **Дата:** 04.10.2026 · **Статус:** реализовано, эпик 12 (см. `STATUS.md`)

Ручка переезжает внутрь, ремешок пряжки укорачивается до язычка, резинок становится две, а вся начинка обложки — карманы, первый вкладыш, обе резинки — входит в цену. Карманы из платной опции «слоты под карты» превращаются в настраиваемую подсистему.

Статусы: **задано** — решение заказчика · **предложение** — допущение аналитика · **мастеру** — временное значение, ждёт мастера.

---

## 1. Карманы

Карман — одна деталь кожи, загнутая и пришитая по трём сторонам. Типы отличаются только высотой загиба.

| Тип | Код в ссылке | Высота | Что кладут |
|---|---|---|---|
| `deep` | `d` | 100 мм | Паспорт, сложенный A4, документы |
| `medium` | `m` | 70 мм | Купюры, билеты, чеки |
| `card` | `c` | 55 мм | Карты, визитки, проездной |
| `corner` | `k` | 45 мм | Уголок, держит лист. Только в самом низу |

| ID | Требование | Статус |
|---|---|---|
| PK-1 | Карманы бесплатны и включены по умолчанию: один `deep` на передней створке. Ось `cardSlots` упразднена | задано |
| PK-2 | Высоты 100 / 70 / 55 / 45 мм | мастеру |
| PK-3 | Стопка снизу вверх, нахлёст 15 мм | задано |
| PK-4 | Любой карман, кроме уголка, можно прострочить посередине — два отделения | предложение |
| PK-5 | Раскладка на обеих створках независимо | предложение |
| PK-6 | Уголок — только самым нижним и только один | предложение |
| PK-7 | Не больше 4 карманов на створку | предложение |
| PK-8 | «Карманы для карт» → «карманы» везде | задано |
| PK-9 | Конструктор показывает бюджет «занято X из Y мм», кнопка неподходящего кармана недоступна | предложение |
| PK-10 | При смене размера на меньший стопка срезается сверху, с тостом | задано |

**Бюджет створки** = высота обложки − 2 × 8 мм: A6 142, B6 170, Standard 204, A5 204.
**Высота стопки** = Σ высот − 15 × (N − 1).
Однотипных влезает: глубоких 1/1/2/2, средних 2/2/3/3, карточных 3/3/4/4.

**Ссылка:** `?pk=d,c+|m` — передняя створка снизу вверх, `|`, задняя; `+` — прострочен. Параметр пишется, только если раскладка отличается от умолчания.

## 2. Две резинки

| ID | Требование | Статус |
|---|---|---|
| K-13 | Резинка-застёжка: две дырки в корешке по центру высоты, охватывает закрытый блокнот поперёк — на уровне пряжки | задано |
| K-14 | Без узла и хвостиков | задано |
| K-15 | Застёжки по-прежнему взаимоисключающие: резинка · пряжка +130 zł · без застёжки | задано |
| K-16 | Резинка блока: по корешку, дырки вверху и внизу корешка | задано |
| K-17 | Резинка блока есть всегда, в цене не участвует | задано |
| K-18 | Рисуется на всех видах, где виден корешок | предложение |
| K-19 | Обе резинки в цвет кожи; ось `elasticColor` удалена целиком | задано |

На чертеже резинка рисуется с тёмной обводкой: она того же цвета, что кожа, и без обводки исчезает.

## 7. Что отменено из спецификации 17

C-1…C-6 (слоты под карты), P-5 (петля снаружи на корешке), K-2 (цвет резинки), K-3 (узелок снаружи задней обложки), K-4 частично (необратимость теперь только про дырки застёжки — дырки резинки блока есть всегда), §8 «вкладыш 25 zł за штуку».

## 8. Вопросы мастеру

1. Высоты карманов и нахлёст.
2. Петля для ручки рядом с карманами на одной створке.
3. Четыре дырки в одном корешке — держит ли кожа.
