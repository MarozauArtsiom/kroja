# 03 — Карта сайта

## MVP: два маршрута

```
/                          Лендинг — носитель сюжетных кадров
/configurator              Конструктор
  ?size=&leather=&color=…  Состояние конфигурации в query
/shotlist              ⭐  Список кадров для съёмки — главный артефакт MVP
```

Плюс корзина — не маршрут, а drawer поверх любой страницы. Собственного URL не имеет: при 1–2 позициях отдельная страница корзины — лишний шаг в воронке.

**Всё.** Три файла страниц. `/shotlist` появился в v0.4: MVP адресован мастеру, и это то, ради чего он открывается (`12-schematic-assets.md`).

## Как две страницы заменяют десять

Контент, который в полноценном магазине живёт на отдельных страницах, в MVP сжат в секции лендинга:

| Обычно отдельная страница | Куда попадает в MVP |
|---|---|
| Каталог `/collection` | Секция «Четыре размера» на лендинге, каждая карточка ведёт в конструктор с преселектом |
| Карточки моделей `/product/*` | Туда же; вся спецификация — в раскрывающейся таблице секции |
| Материалы `/leather` | Секция «Кожа» с макро-фото и вкладками по типам |
| О мастерской `/craft` | Секция «Как это делается» с фото процесса |
| Уход `/care` | Аккордеон в секции «Кожа» |
| FAQ | Аккордеон-секция в конце лендинга |
| Доставка | Одна строка в FAQ: «Отправляем по всей Европе, срок изготовления N дней» |
| Контакты | Футер |

Это не компромисс, а осознанное решение: длинный продающий лендинг для одного продукта конвертирует лучше, чем разнесённый по страницам сайт, потому что не даёт пользователю потеряться и держит один непрерывный аргумент.

## Навигация MVP

**Шапка (sticky, минималистичная):**
`KROJA` (логотип, → верх страницы) · `Materials` · `Craft` · `FAQ` (якорные ссылки) · **`Build yours`** (→ `/configurator`) · **`Shot list`** (→ `/shotlist`) · иконка корзины

Ссылка `Shot list` в MVP видна открыто — прятать её незачем, зритель один и пришёл именно за ней.

**В конструкторе шапка сжимается:** только логотип (← назад на лендинг) и корзина. Никаких отвлекающих ссылок — пользователь внутри задачи.

**Футер (короткий):** логотип, одна строка о бренде, город (Kraków, Poland), email, Instagram, © год. Юридических ссылок в MVP нет — см. `11-legal-and-open-questions.md`.

## Фаза 2 и далее

Полная карта на будущее — в `10-deferred.md`. Кратко порядок появления страниц:

1. Чекаут и подтверждение заказа (открывает продажи)
2. `/leather` и `/craft` как самостоятельные страницы (SEO, глубина доверия)
3. `/refills` и `/accessories` (LTV, допродажа)
4. Юридические страницы (обязательны к моменту первой реальной продажи)
5. `/corporate` (канал B2B)
6. Польская и немецкая локали

## Правило расширения

Новая страница добавляется только когда для неё есть:
1. свой поисковый интент или свой источник трафика,
2. контент, который физически не помещается в секцию лендинга.

Иначе — секция. Сайт из двадцати страниц с четырьмя товарами выглядит как пустой магазин, и это заметно.
