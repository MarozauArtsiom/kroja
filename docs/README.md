# Naked Skin — документация

Сайт бренда кожаных обложек для блокнотов ручной работы из Кракова. Лендинг, конструктор обложки и служебный список кадров для будущей съёмки. Шесть языков, без бэкенда и базы данных, без фотографий — весь визуал построен на SVG-чертежах.

Документация описывает систему **такой, какая она есть сейчас**. История того, как она к этому пришла, — в `git log` и `STATUS.md`; здесь только итог и решения, которые важно не потерять.

## Быстрый старт

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000` — middleware перенаправит на язык браузера.

Перед коммитом:

```bash
npx tsc --noEmit && npm run lint && npm run build
```

`npm run lint` включает проверку переводов: она падает, если в коде есть текст мимо словаря.
