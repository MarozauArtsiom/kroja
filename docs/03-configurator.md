# 03 — Конструктор изнутри

## Модель

Всё, что выбирает покупатель, — один тип `Configuration` в `types/config.ts`:

```ts
interface Configuration {
  size: 'a6' | 'b6' | 'standard' | 'a5';
  leather: 'smooth' | 'croc' | 'suede';
  color: ColorCode;                       // 9 цветов
  thread: 'tonal' | 'linen' | 'cream' | 'black' | 'brown' | 'navy';
  closure: 'elastic' | 'buckle' | 'none';
  penHolder: 'none' | 'slim' | 'wide';
  pockets: { front: Pocket[]; back: Pocket[] };   // снизу вверх
  embossing: { text; font; position } | null;
  inserts: { type: 'plain' | 'ruled' | 'dot'; qty }[];
  giftBox: boolean;
}

interface Pocket { kind: 'deep' | 'medium' | 'card' | 'corner'; divided: boolean }
```

Производное (цена, срок, статус наличия, ключ превью) не хранится, а считается — `PricedConfiguration` в момент добавления в корзину.

### Значения по умолчанию

`DEFAULT_CONFIG` в `lib/config-schema.ts`: A5, гладкая кожа, коньяк, нить в тон, резинка, без петли, один глубокий карман на передней створке, без тиснения, один вкладыш в точку, без коробки. Цена — 300 zł.

## Три стадии разбора

Любая конфигурация — из ссылки, из localStorage, из тела запроса — проходит одни и те же стадии и **никогда не роняет страницу**.

### 1. Схема (`lib/config-schema.ts`)

Каждое поле — Zod с `.catch(значение_по_умолчанию)`. Неизвестная кожа становится гладкой, неизвестный размер — A5 и так далее. Лишние поля (например, из старых версий модели) отбрасываются.

Карманы разбираются помягче: битые элементы списка выбрасываются по одному, а не весь список целиком. Если сломана сама структура — возвращается раскладка по умолчанию.

Тиснение проходит санитайзер `sanitizeEmbossing`: поднять регистр, выбросить всё, кроме букв латиницы, польских, кириллицы и Ў І Ї Є Ґ, обрезать до двух. Пустой результат — тиснения нет.

### 2. Правила (`lib/availability.ts › resolveConfiguration`)

Типы верны, но комбинация может быть невозможной. Пять правил по порядку:

| # | Правило | Что делает | Сообщает |
|---|---|---|---|
| 1 | Размер главнее кожи | Если кожа не кроится в этом размере — первая подходящая кожа | `leather` |
| 2 | Цвет должен быть в коже и в наличии | Иначе — ближайший доступный по порядку цветов | `color` |
| 3 | Вкладыши ≤ вместимости размера | Срезает с конца списка | `inserts` |
| 4 | Вкладышей ≥ 1 | Пусто → один вкладыш по умолчанию | молча |
| 5 | Карманы в рамках правил | Для каждой створки — `normaliseStack` (ниже) | `pockets` + створка |

Правило 4 молчит, потому что интерфейс не даёт обнулить вкладыши — пустой список приходит только из старой ссылки или корзины, и сообщать покупателю не о чем.

Результат — валидная конфигурация и список `ConfigChange`. Это коды, а не фразы: `lib/` не знает языка. Фразу из кода собирает `components/configurator/change-message.ts` по словарю.

Правила 1 и 2 сейчас не срабатывают — все кожи доступны во всех цветах и размерах, — но механизм работает и включится, как только в данных появятся ограничения.

### 3. Цена (`lib/pricing.ts › calculatePrice`)

```
итого = база размера
      + надбавка кожи
      + цена нити            (сейчас 0 у всех)
      + цена застёжки        (130 zł у пряжки)
      + цена петли           (20 zł у любой петли)
      + тиснение             (40 zł, если есть буквы)
      + вкладыши             (25 zł × (количество − 1))
      + коробка              (35 zł)
```

У карманов строки нет — они бесплатны. Каждое слагаемое берётся либо из данных (`threads[code].priceMinor`, `closures[code].priceMinor`, `penHolders[code].priceMinor`), либо из именованной функции рядом с ценой (`insertsPriceMinor` в `content/pricing.ts`). В `calculatePrice` нет ни одного условия с ценой — чтобы изменить цену, правят данные.

`insertsPriceMinor` раскладывает вкладыши на единицы, сортирует по цене и отбрасывает самую дешёвую. Сейчас все типы стоят одинаково, но правило «первый бесплатно» останется честным, даже если типы когда-нибудь подорожают по-разному.

## Ссылка

Пишутся только отличия от значений по умолчанию — ссылка короткая и читаемая.

| Параметр | Пример | Когда пишется |
|---|---|---|
| `size`, `leather`, `color` | `size=b6` | всегда |
| `thread` | `thread=cream` | если не «в тон» |
| `closure` | `closure=buckle` | если не резинка |
| `pen` | `pen=wide` | если петля есть |
| `pk` | `pk=d,c+\|m` | если раскладка карманов не по умолчанию |
| `emboss`, `font`, `pos` | `emboss=AB&font=sans&pos=spine` | если есть тиснение |
| `inserts` | `inserts=2:dot,1:ruled` | всегда |
| `box` | `box=1` | если коробка |

### Формат карманов

```
pk = <передняя створка> | <задняя створка>
створка = карманы через запятую, снизу вверх
карман = буква [+]

d = deep   m = medium   c = card   k = corner   + = прострочен посередине
```

| Ссылка | Значение |
|---|---|
| нет `pk` | раскладка по умолчанию: один глубокий спереди |
| `pk=\|` | карманов нет совсем |
| `pk=d,c+\|m` | спереди глубокий и карточный с прострочкой, сзади средний |
| `pk=k,c,c\|` | спереди уголок и два карточных, сзади пусто |

Неизвестные буквы выбрасываются молча. Невозможная раскладка (уголок не внизу, больше четырёх, не влезает в бюджет) чинится правилом 5 с предупреждением.

## Карманы: математика

Всё — в `lib/pockets.ts`, чистые функции без React.

**Бюджет створки** — высота обложки минус поля под шов и кромку, 8 мм сверху и снизу:

```
pocketBudgetMm(size) = coverMm[1] − 16
A6 → 142    B6 → 170    Standard → 204    A5 → 204
```

**Высота стопки** — сумма высот минус перекрытия:

```
stackHeightMm(stack) = Σ heightMm − 15 × (N − 1)        (0 для пустой стопки)
```

**Положение каждого кармана** от низа рабочего поля — `pocketSpans`:

```
карман 0: от 0 до h₀
карман i: от (верх кармана i−1) − 15 до него же + hᵢ
```

Пример, глубокий + карточный: глубокий 0–100 мм, карточный 85–140 мм. Карточный выглядывает над глубоким на 40 мм.

### Проверки

| Функция | Отвечает на вопрос | Правила |
|---|---|---|
| `canAddPocket(stack, kind, size)` | Можно ли положить сверху ещё один? | Не больше 4; уголок только на пустую створку; новая высота ≤ бюджета |
| `canMovePocket(stack, i, 'up' \| 'down')` | Можно ли поменять местами с соседом? | Сосед существует; ни один из двух — не уголок |
| `normaliseStack(stack, size)` | Привести к допустимому | Уголок только на позиции 0; уголок никогда не прострочен; первые 4; срезать сверху, пока не влезет |

Интерфейс использует первые две, чтобы выключать кнопки. `resolveConfiguration` использует третью, чтобы чинить то, что пришло снаружи — из ссылки, старой корзины, при уменьшении размера.

### Сколько влезает

| Размер | Бюджет | Глубоких | Средних | Карточных | Пример впритык |
|---|---|---|---|---|---|
| A6 | 142 | 1 | 2 | 3 | глубокий + карточный = 140 |
| B6 | 170 | 1 | 2 | 3 | глубокий + средний = 155 |
| Standard | 204 | 2 | 3 | 4 | глубокий + средний + карточный = 195 |
| A5 | 204 | 2 | 3 | 4 | то же |

## Раскладка страницы

`ConfiguratorClient.tsx` собирает страницу из трёх частей:

- **Превью.** С `lg` — полное превью слева, закреплено (`Preview.tsx`, со схемой размеров). Ниже `lg` — `MobilePreview.tsx`: полоса под заголовком страницы, закреплена `sticky top-0`, компактный чертёж и столбик вкладок ракурсов; нажатие на чертёж открывает крупный вид в модалке. Полоса — прямой ребёнок `<main>`: внутри ячейки сетки `sticky` не работает. Схема размеров ниже `lg` открывается кнопкой «Сравнить с телефоном» в секции «Размер».
- **Основное.** Размер, кожа, цвет, застёжка — открытые секции (`OptionSection` без `onToggle`, заголовок `h2`).
- **«Детали».** Нить, петля, карманы, вкладыши — свёрнутые строки (`OptionSection` с `onToggle`, заголовок `h3`, кнопка с `aria-expanded`). Сводки строк считает `summary.ts › detailSummaries` из конфигурации и словаря. Затем открытое «Тиснение» и переключатель подарочной коробки (`GiftBoxToggle.tsx`, `role="switch"`).

Селекторы сами заголовков не рисуют — заголовок и цена в строке сводки принадлежат `OptionSection`. На узком экране карточки кожи, застёжки и петли — строки (`OptionCardGroup rowOnMobile`). Круги диаметров петли — только с `md`.

**Ракурс превью** — `usePreviewAngle(config)`: одно состояние на страницу. Меняется вкладками любого превью, автоматически — при изменении того, что видно только внутри (D-19), при раскрытии строк «Петля», «Карманы», «Вкладыши» и при фокусе в поле тиснения (вид спереди).

## Редактор карманов (`PocketsSelector.tsx`)

Сверху — четыре готовые раскладки (`content/pocket-presets.ts`): «Без карманов», «Для документов», «Для карт», «Документы и карты». Выбранная определяется по самой раскладке (`matchPocketPreset`); если раскладка своя — пятая карточка «Своя раскладка» и ручной редактор открыт. Иначе ручной редактор спрятан под «Настроить вручную».

Ручной редактор — две карточки, передняя и задняя створка. В каждой:

- **полоса бюджета**: «занято 140 из 204 мм» и заполненная доля;
- **список карманов сверху вниз** — в том порядке, в каком их видно на обложке; подписи «верх» и «низ»;
- у каждого кармана: название, что в него кладут, флажок «разделить на два» (кроме уголка), кнопки ↑ ↓ × с подписями для скринридера;
- **четыре кнопки добавления**; неактивная кнопка показывает причину из `addPocketBlocker`: «не больше четырёх», «только на пустую створку», «не хватает места».

Миллиметры карманов в интерфейсе — только в полосе бюджета.

Новый карман кладётся сверху стопки. ↑ поднимает карман на одну позицию, ↓ опускает.

## Вкладыши (`InsertsSelector.tsx`)

Три счётчика по типам. Под заголовком — «до N в этом размере, выбрано M» и «первый включён, каждый следующий 25 zł».

Границы каждого счётчика:

```
максимум типа = текущее + (вместимость − всего выбрано)
минимум типа  = max(0, 1 − (всего выбрано − текущее))
```

Второе значит: если этот тип держит единственный вкладыш, минус недоступен. Обнулить корзину вкладышей из интерфейса нельзя.

## Чертёж

Чертёж не меняет геометрию обложки при смене размера — масштаб показывает отдельная схема габаритов. Исключение — карманы на развороте: их высота масштабируется бюджетом размера, чтобы глубокий карман в A6 выглядел заметно крупнее, чем в A5. Это правда об изделии, а не искажение.

`schematicParts(config, dict)` один раз выводит всё, что нужно всем видам: цвет кожи, штриховку, цвет стежка (для нити «в тон» — цвет кожи), цвет резинок (тоже цвет кожи), флаги застёжки и петли, радиус ручки, подписи на языке страницы.

### Четыре вида

| Вид | Холст | Что показывает |
|---|---|---|
| **Front** | 400 × 500 | Обложка спереди. Резинка блока вдоль корешка с дырками вверху и внизу. Застёжка: две полосы поперёк из двух дырок в корешке — или короткий язычок с латунной рамкой у наружного края. Тиснение в углу или на корешке |
| **Back** | 400 × 500 | Зеркало переднего. Четыре дырки в корешке, крепление язычка пряжки с коробчатым швом у наружного края |
| **Open** | 400 × 300 | Разворот. Слева — передняя створка: петля с ручкой у наружного края, карманы рядом. Справа — задняя створка: карманы под вкладышами. По корешку — резинка блока |
| **Detail** | 400 × 400 | Макро угла: шов, кромка, подпись толщины нити |

Под каждым видом — выноски (до трёх строк) и плашка «схематический чертёж, не фото». Имени файла кадра под чертежом нет — оно есть только на `/shotlist`.

### Приёмы отрисовки

- **Резинка с обводкой.** Резинка того же цвета, что кожа, поэтому рисуется поверх тёмной линии чуть шире (`Band` в `schematic-parts.tsx`). Без этого коньячная резинка на коньячной коже не видна.
- **Прострочка с тёмной подложкой.** Шов посередине кармана рисуется поверх полупрозрачной тёмной линии — при нити «в тон» стежок сливается с кожей, а разделение должно читаться.
- **Нижние карманы поверх верхних.** Стопка рисуется сверху вниз, так что каждый нижний карман перекрывает верхний — как в настоящем пришитом кармане.
- **Вкладыши контуром, когда сзади есть карманы.** Вкладыши лежат на задней створке. Если там есть карманы, вкладыши рисуются пунктирным контуром без заливки, чтобы карманы под ними оставались видны.
- **Координаты дырок в корешке — одна константа.** `SPINE` в `schematic-parts.tsx` задаёт их для вида спереди; вид сзади зеркалит (`400 − x`). Поменять положение дырок — одна правка.

### Превью переключается само

`usePreviewAngle.ts` следит за ключом «всего, что видно только внутри»: раскладка карманов, петля, количество вкладышей. Когда он меняется — вкладка переключается на Open. Без этого покупатель жмёт «+» у карманов, глядя на вид спереди, и не видит никакого результата. Первая отрисовка ничего не переключает.

## Корзина и тиснение

Кнопка «в корзину» в нижней панели. Если есть тиснение — сначала модалка: буквы крупно в выбранном начертании и предупреждение, что изделие с тиснением не возвращается. Подтвердил — позиция в корзине и корзина открыта.

В строке позиции корзины — все оси человеческими словами: размер, кожа, цвет, нить, застёжка, петля, карманы по створкам («Передняя створка: Глубокий, Для карт (разделить на два) · Задняя створка: Средний»), тиснение, вкладыши, коробка, срок. Под позицией с резинкой — напоминание про дырки в корешке.
