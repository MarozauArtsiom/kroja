# 04 — Шесть языков

## Правило

**Текст, который видит пользователь или читает скринридер, живёт в словаре и переводится на все языки сайта.** Сюда входят подписи на чертежах, `aria-label`, alt-тексты, тосты, метаданные страниц, экспорт списка кадров. Не входят: комментарии в коде, коды осей, имена файлов вида `smooth_cognac_front.webp`, CSS.

Правило проверяется автоматически — `npm run lint` падает, если в коде появился текст мимо словаря.

## Языки

| Код | Язык | Особенности |
|---|---|---|
| `en` | English | Язык по умолчанию и эталон для остальных |
| `pl` | Polski | Основной рынок |
| `de` | Deutsch | |
| `by` | Беларуская | Кириллица; единицы `мм`, `г` |
| `uk` | Українська | Кириллица; единицы `мм`, `г` |
| `ru` | Русский | Кириллица; единицы `мм`, `г`. Последний в списке |

Порядок в `SUPPORTED_LOCALES` — это порядок в переключателе. Новый язык ставится в конец.

Код `by` — не стандарт ISO (`be`), но так исторически названы маршруты; `normalizeLocale` понимает оба.

### Переключатель

В шапке — кнопка с кодом языка (`RU`) и выпадающий список: двухбуквенный код и название языка на нём самом (`Русский`). **Флагов нет:** язык — это не страна, и флаг оставлял часть читателей без «своего» значка (белорусский, русский и украинский делят одну аудиторию, а английский и немецкий — по несколько стран). Подпись кнопки для скринридера — `dict.a11y.currentLanguage`.

## Как выбирается язык

`middleware.ts` срабатывает на любой адрес без языкового префикса:

1. cookie `NEXT_LOCALE` — если пользователь уже выбирал язык переключателем;
2. первый язык из заголовка `Accept-Language`;
3. иначе `en`.

Браузер с `ru-RU` попадёт на `/ru`, с `be-BY` — на `/by`, с `uk-UA` — на `/uk`, с неизвестным языком — на `/en`. Дальше всё живёт под `/{lang}/…`. Каждая страница генерируется статически для каждого языка. Переключатель в шапке пишет cookie и ведёт на ту же страницу с тем же набором параметров, но под другим префиксом — конфигурация в конструкторе при смене языка не теряется.

## Где лежат тексты

| Что | Где |
|---|---|
| Форма словаря | `types/i18n.ts` — интерфейс `Dictionary` |
| Тексты | `content/i18n/dict/{en,pl,de,by,uk}.ts` |
| Выбор словаря | `content/i18n/index.ts › getDictionary(lang)` |
| Доступ из компонентов | `useI18n()` → `{ locale, dict, switchLocale, getLocalizedPath }` |
| Доступ на сервере (метаданные) | `getDictionary(lang)` в `generateMetadata` |

### Разделы словаря

| Раздел | Что в нём |
|---|---|
| `brand`, `nav`, `hero`, `reasons`, `sizes`, `leather`, `process`, `included`, `faq`, `finalCta`, `footer` | Лендинг |
| `configurator` | Подписи шагов и подсказки конструктора |
| `options` | **Названия того, что выбирает покупатель**: застёжки, петли, карманы, створки, начертания и позиции тиснения, «готово через N дней». Читают и конструктор, и корзина |
| `cart` | Корзина и резерв |
| `shotlist` | Список кадров: правила съёмки, что показать в каждом ракурсе, 11 сюжетных кадров |
| `schematic` | Всё, что нарисовано на чертежах, и `aria-label` чертежей |
| `conflicts` | Тосты, когда конструктор сам меняет выбор, и причины недоступности опций |
| `a11y` | Подписи только для скринридера |
| `illustrations`, `meta`, `units`, `notFound` | Alt иллюстраций **и текст, нарисованный внутри них**, метаданные, единицы измерения, страница 404 |
| `colors`, `threads`, `insertTypes`, `leatherNames`, `angles` | Названия значений по кодам |

Разделение `configurator` / `options` важно: корзина не должна зависеть от подписей конструктора. Название варианта — в `options`, подсказка вокруг выбора — в `configurator`.

## Полноту проверяет компилятор

## Иллюстрации с текстом

Две иллюстрации лендинга — «две нити, одно отверстие» и «одна обложка, много вкладышей» — содержат подписи. Подпись внутри картинки перевести нельзя: `<Image src="….svg">` загружает файл как изображение, и его текст недоступен ни словарю, ни скринридеру. Поэтому такие иллюстрации — **встроенные SVG-компоненты** (`components/landing/illustrations/`), а текст берётся из `dict.illustrations`. Цвета — из токенов и данных, а не копии хексов.

Иллюстрация без текста (`hero.svg`) остаётся обычным файлом.

**Правило для новых иллюстраций:** есть слова — встроенный компонент и ключи в словаре; слов нет — файл в `public/illustrations/`.

Подписи рисуются в фиксированной рамке 400 единиц, а немецкий и русский длиннее английского. При добавлении языка или правке подписей проверяйте, что текст не выходит за край: самая широкая строка сейчас — русская «Много вкладышей», правый край на 382 из 400.

## Полноту проверяет компилятор

Словарь типизирован кодами осей, а не просто строками:

```ts
options: {
  pockets: Record<PocketKind, { title: string; meta: string }>;
  flaps: Record<Flap, string>;
  …
}
colors: Record<ColorCode, string>;
```

Добавили новый цвет или тип кармана в `types/config.ts` — все словари перестают компилироваться, пока в каждом не появится перевод. Пропустить язык невозможно.

Английские названия в `content/*.ts` (`name: 'Cognac'`) остались значениями по умолчанию для логов и скриптов. Интерфейс их не показывает — только словарь.

## Плейсхолдеры

Фразы с числами не собираются из кусков в компоненте. В словаре — шаблон, в коде — `fill()` из `lib/format.ts`:

```ts
// dict
pocketsBudget: 'Zajęte {used} z {budget} mm'
// компонент
fill(dict.configurator.pocketsBudget, { used: 140, budget: 204 })
```

Порядок слов в каждом языке свой, поэтому шаблон целиком принадлежит переводу. Отсутствующий плейсхолдер подставляется пустой строкой, а не `undefined`.

## Сообщения из логики

`lib/` не знает про язык. Когда правило меняет выбор, оно возвращает **код**:

```ts
{ kind: 'pockets', flap: 'front', size: 'a6' }
```

Фразу собирает `components/configurator/change-message.ts` по словарю: `«Przednia strona: kieszenie przycięte do rozmiaru A6 Kieszonkowy»`. Причины недоступности опций (`OptionState`) устроены так же — код без текста.

## Детектор пропусков

`npm run i18n` → `scripts/check-i18n.mjs`. Печатает две вещи:

| Раздел | Что ищет |
|---|---|
| A. Переводы есть, код не использует | Ключи `Dictionary`, к которым никто не обращается через `dict.…` |
| B. Текст мимо словаря | Читаемые человеком строки в коде: текст внутри JSX (только `.tsx`); слова рядом с выражением (`{n} mm`, `Цена: {x}`); значения `aria-label`, `alt`, `placeholder`, `title`, `label` — и в кавычках, и выражением, и шаблонной строкой с `${…}`; строки и шаблоны в `lib/`, `content/`, `store/` |

Код выхода 1, если найдено хоть что-то. Детектор подключён к `npm run lint`.

### Список исключений

`scripts/i18n-allowlist.json` — то, что пользователь не читает как текст: имена шрифтов, MIME-типы, заголовки колонок экспортируемых файлов, служебные строки API. Плюс файлы `content/*.ts` с английскими значениями по умолчанию — их полноту гарантирует компилятор через `Record`-ключи словаря.

**Добавлять строку в исключения, чтобы детектор замолчал, нельзя.** Если пользователь это видит — нужен ключ в словаре.

## Как добавить текст

1. Поле в интерфейсе `Dictionary` (`types/i18n.ts`), с комментарием про плейсхолдеры, если они есть.
2. Значение в `en.ts`.
3. Значения в `pl.ts`, `de.ts`, `by.ts`, `uk.ts` — компилятор покажет, где забыто.
4. В компоненте — `dict.раздел.ключ`, при необходимости через `fill()`.
5. `npm run lint` — детектор подтвердит, что старого текста в коде не осталось.
